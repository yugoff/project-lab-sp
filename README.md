# RAG Ассистент для корпоративных ролей

Это **RAG (Retrieval-Augmented Generation) система**, предназначенная для быстрого поиска информации и генерации ответов по корпоративным процессам. Система позволяет задавать вопросы и получать ответы на основе **контекста из FAISS-векторной базы знаний**, разделённой по ролям.

## Доступные возможности

- **Выбор роли ассистента**:  
  Пользователь может выбрать одну из ролей:
  - `HR` – кадры, отпуск, больничные, декрет и др.
  - `Finance` – бухгалтерия, налоги, отчётность, бюджет
  - `ERP` – управление заказами, склад, производство, закупки

- **Запросы к FAISS**:  
  Система ищет релевантные знания по выбранной роли в FAISS индексе и использует их как контекст для LLM.

- **Генерация ответа LLM**:  
  На основе найденного контекста формируется краткий и понятный ответ на вопрос пользователя.

## Структура проекта

- `scripts/roles_index.faiss` – FAISS индекс
- `backend/app.py` – основной бэкенд FastAPI
- `frontend/app.py` – интерфейс Streamlit

## Запуск системы

Для работы RAG-системы нужно запустить **два сервиса**:

1. **FastAPI бэкенд**  
   В отдельном терминале:
   ```bash
   fastapi run backend/app.py

2. **Streamlit фронтенд**
   В отдельном терминале:
   ```bash
   streamlit run frontend/app.py
